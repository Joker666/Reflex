Install

Ready to streamline your web workflow? Set up takes less than 60 seconds.

1. Install

Run brew install --cask Joker666/tap/reflex or download the release DMG from GitHub.

2. Set Default

Click "Make Reflex Default Browser" so macOS dispatches all clicked HTTP and HTTPS links to Reflex.

3. Discover

Reflex automatically scans for Chrome, Safari, Dia, Comet, Helium, Edge, Phi, Zen, and Firefox plus profiles.

4. Add Purpose

Write brief phrases like "Work accounts and GitHub" or "Personal reading". Jev handles the rest.

OPTION ⌥
+

Hold Option, then click

Want to bypass automatic AI selection for a specific link? Hold the ⌥ Option key when clicking to open the chooser directly. You can configure this modifier to Control, Shift, Command, or Fn in Settings.

Privacy by Design

Built exclusively for macOS with local-first security principles.

01

Zero Link History

Reflex never writes clicked links to disk, databases, logs, or analytics. URLs live in memory only for the fraction of a second required to dispatch them.

02

Privacy-Preserved Routing

All query parameter values and URL fragments are stripped before routing. Only the scheme, host, path, and source app are sent to the AI decision model.

03

Direct Native Launch

Your target browser always receives the full, original link directly via native macOS NSWorkspace and process arguments — never through an unsafe shell.
